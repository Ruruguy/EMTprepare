# 🚑 急救耗材特攻隊（救護器材手勢拿取遊戲）

結合**「超級雞馬」（Ultimate Chicken Horse）派對物理趣味風格**與**緊急救護技術員（EMT）實務處置訓練**的體感互動遊戲。

## 🌟 遊戲亮點

1. **體感鏡頭手勢偵測（MediaPipe Hands）**
   - 透過手機、平板或電腦的鏡頭，即時追蹤手部骨骼動作。
   - **大拇指與食指捏合（Pinch）**：抓取耗材。
   - **平移手掌**：拖曳耗材至救護包。
   - **張開手掌**：投放至救護包。
   - **免鏡頭雙模保底**：若無鏡頭或光源不佳，亦支援滑鼠與觸控直接拖曳。

2. **超級雞馬風格物理與趣味音效**
   - 物品抓取時具有慣性傾斜與 Q 彈搖擺動態。
   - 救護包張嘴吸入、吞下與彈性震盪。
   - 抓錯耗材滑稽彈簧波音震退、扣時懲罰與連擊中斷。
   - Web Audio API 原生音效引擎，免載大型音訊檔案。

3. **日式簡約文青手繪風格（39 款精緻 SVG）**
   - 全套 39 種救護器材皆以向量 SVG 純手工繪製。
   - 和紙溫潤質地（`#FAF7F2`）與柔和莫蘭迪配色。
   - 內建「救護耗材文青圖鑑」，可隨時瀏覽所有器材適應症與中文規格。

4. **EMT 救護技術員實戰出勤題庫**
   - OHCA 心肺功能停止、大動脈噴血、車禍頸椎創傷、急性氣喘、低血糖、急產接生、精神急症、大面積燙傷等多元急症。
   - 每回合均提供處置詳解與救護小百科叮嚀。

## 🚀 啟動方式

在專案目錄下執行：

```bash
# 開發伺服器（推薦，支援熱重載與即時測試）
npm run dev

# 或是開啟生產預覽伺服器
npm run preview
```

瀏覽器打開 `http://localhost:3000` 或 `http://localhost:4173` 即可遊玩！
